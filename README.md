# Controle de Gastos Pessoais

Este é meu primeiro projeto de programação, desenvolvido durante meus estudos de Análise e Desenvolvimento de Sistemas (ADS).

## Objetivo
Criar uma aplicação para ajudar no controle de gastos pessoais.

## Funcionalidades
- Registrar despesas
- Informar descrição e valor
- Categorizar os gastos
- Calcular o total de despesas
- Consultar o saldo disponível

## Tecnologias
- HTML
- CSS
- JavaScript

## Status
Em desenvolvimento.

## Aprendizados
Este projeto tem como objetivo praticar lógica de programação e desenvolvimento web.
